# FontCop — 字体版权快查

开源字体版权识别工具。上传/粘贴截图 → 框选或自动提取截图中的字 → 与内置**开源字体白名单**做**字形级（字形结构，非仅名称）比对** → 给出「可放心用 / 疑似 / 有风险 / 无法判断」四态结论，并逐字可视化每个字投给哪些字体、各投多少分。

> 判定为字形级参考，不构成法律意见。

---

## 一、项目说明

### 这是什么

很多截图里的字体一眼认不出是哪款、能不能商用。FontCop 的做法是「**白名单字形比对**」：

1. 你把截图拖进来（或 ⌘V / Ctrl+V 粘贴）。
2. 在图上框选几个字（或点「🔍 自动识别」让 OCR 自动提取）。
3. 服务端 OCR 识别出字 → 把每个字渲染成候选字体各自的可比字形 → 做**字形级相似度**打分（灰度→二值→有向距离场/直方，逐字投票聚合到字体）。
4. 前端按投票画**堆叠横条图**：每个字一段，段内按候选字体得分比例着色并附图例；顶部给出汇总结论。

### 判定四态

| 状态 | 前端文案 | 含义 |
|------|----------|------|
| `free` | ✅ 免费字体 | 命中开源白名单，相似度达标，可放心使用 |
| `suspect` | 🤔 疑似免费 | 与开源字体相似但非精确匹配 |
| `risky` | ⚠️ 版权风险 | 与白名单差异过大，大概率商业版权 |
| `unknown` | ❓ 无法判断 | 识别区域没有**可比对的字**（如 0 可比字 / OCR 空跑），**不给吓人的结论** |

**设计取舍（重要的坑）**：过去在「没有可比对的字」时会兜底判 `risky` + 相似度 0%，制造「没证据却给你扣版权帽子」的观感（用户明确反馈过「这会让人觉得你不靠谱」「失败却残留疑似免费81%」）。当前实现：
- 后端：空兜底返回 **`unknown`**（中性灰），不再伪装成确定判定。
- 前端：图表渲染不再因 `nameById` 未定义而误报「识别失败」；渲染失败时上屏中性态，不残留旧判定。

### 怎么跑

```bash
python src/server.py          # 或 run.py；默认 http://127.0.0.1:8642
```

首次会自动建字体索引（白名单字形库），OCR 用内置 RapidOCR（ONNX，无需联网）。

### 怎么用

```
拖入图片 / ⌘V 粘贴截图
  → 手动：在图上框选字，弹层输入该字 → 开始识别
  → 自动：点「🔍 自动识别」，OCR 自动提取截图中的字
  → 右上角可看 开源字体清单 / 关于
```

## 二、开发内容（技术栈与模块）

纯 Python 标准库 + 少量科学计算，无框架依赖。

### 目录结构

```
fontcop/
├─ src/
│  ├─ server.py      HTTP 服务：静态托管 + API（/api/match /api/auto /api/fonts）
│  ├─ auto.py        /api/auto：OCR 自动提取字符 → 聚合投票 → 四态判定（空兜底 unknown）
│  ├─ features.py    字形级比对核心：二值 / IoU / 有向距离场 / NCC / HOG 相似度 + 阈值常量
│  ├─ pipeline.py    编码→字形比对→聚合 的管线抽层（OCR 与手动共用）
│  ├─ indexer.py     白名单字体 → 字形索引
│  ├─ render.py      字形 → 可渲染样本位图
│  └─ tray.py        系统托盘（可选）
├─ web/
│  ├─ index.html     页面骨架（图片区 + 结果区 + 弹层）
│  ├─ app.js         前端逻辑：拖拽/粘贴/框选/自动识别/结果渲染（含逐字堆叠图 + 名映射守卫）
│  └─ style.css      样式（含 fixed 判定色 / unknown 中性灰）
├─ fonts/            内置开源字体（SIL-OFL 1.1 等）→ fonts.json 白名单
└─ tests/            自检
```

### 核心算法（features.py）

- **字形归一化**：灰度 → OTSU 二值 → 归一化到固定 SDF 网格。
- **相似度度量**：`iou_similarity`（交并比）、`ncc_aligned`（归一化互相关，2px 内对齐抗偏移）、`hog_similarity`（8×8 方向直方）。
- **判定阈值**（`features.py`）：
  - `THRESHOLD_FREE = 0.90`：相似度 ≥ 0.90 → ✅ 免费
  - `THRESHOLD_SUSPECT = 0.75`：≥ 0.75 但 < 0.90 → 🤔 疑似
  - 其余 → ⚠️ 版权风险
  - **无可比字 → ❓ unknown**（不在上面三分支里吓人）

### 判定聚合（auto.py `_assemble`）

按字体投票聚合：每个可比字各自贡献 `(font_id, score)`，最后**按字体汇总**（`per_font`），取票数最多/均分最高的字体，匹配白名单元数据（名称、许可证、来源）得四态结论与候选列表。空输入直接走中性 `unknown` 兜底。

### API

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/match` | POST | 手动框选：`{image_b64, marks:[{x1,y1,x2,y2,char}]}` → 聚合判定 |
| `/api/auto` | POST | 自动识别：`{image_b64}` → OCR 提取 → 聚合判定 |
| `/api/fonts` | GET | 白名单字体列表 |
| `/` `/app.js` `/style.css` | GET | 前端静态资源 |

### 前端亮点

- **逐字堆叠图**：`renderResult` 把每个参与比对的字画成一段横条，段内按候选字体得分比例着色（颜色由 `font_id` 哈希稳定映射），并附图例（颜色→字体名）和「不同于汇总结论的字」列表。
- **名映射守卫**：图标渲染依赖 `font_id → 名称` 映射，代码从响应候选+逐字 top 自建映射，杜绝「图表渲染因未定义变量崩溃 → 误报识别失败」的旧坑。
- **失败不残留**：识别失败/空结果只渲染中性态，不残留上一条的吓人判定。
